# cf_modeling/deprecated

Archived, unmaintained code for connective-field analyses of the "CCA" ROIs (`cca_a`, `cca_p`), anterior and posterior temporal regions obtained by thresholding group representational-similarity searchlight maps, together with the scripts that read those maps and their run script (`run_analysis.sh`). The current pipeline is in `../`. Output paths inside these scripts have not been updated for the move into this directory, so pass explicit output directories.
