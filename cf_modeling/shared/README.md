# CF Modeling Shared — Ridge and Residualization Utilities

Provides banded ridge regression and residualization helpers reused across CF model fitting.

## Modules

| Module | Purpose |
|--------|---------|
| `ridge_utils.py` | Build himalaya MultipleKernelRidgeCV pipelines, LBOE projection, null-R² computation, and leave-one-run-out CV helpers (including vicsompy's generate_leave_one_run_out) |
