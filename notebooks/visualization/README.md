# Visualization notebooks

Run from the repository root in the `movie` environment; every notebook is executed in place and leaves its figures inline and under `outputs/`.

| Notebook | Figures |
|---|---|
| `main_figures.ipynb` | Mean and maximum held-out Pearson r over cortex against layer for each model |
| `comparison.ipynb` | Spearman correlation of the `shared_av` maps of four pairs with the Margulies gradients and myelin, hexbins, and mean `shared_av` per Yeo 7 network |
| `supp_embedding_plots.ipynb` | PE-AV audio-video cosine similarity matrix, audio, video and joint RDMs, matched versus unmatched segment similarity |
| `cf_modeling_figures.ipynb` | Connective-field split R² flat maps and inflated views for 3b x V1, A1 x V1 and A5 x FFC |
| `time_resolved_figures.ipynb` | Time-resolved audio, video, shared and joint-embedding series with flag strips, label-correlation bars and flat maps |
| `time_resolved_partition_figures.ipynb` | A5, FFC and STSdp audio, video, joint and shared series of PE-AV for four label-removal conditions with the four runs on one axis, label-part bars with block-shuffle null intervals and partial correlations |
